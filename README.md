# 神経衰弱ゲーム

ブラウザで動作するユーザー対コンピューターの神経衰弱ゲームです。

## ゲームルール

- 8種類の絵文字カードが2枚ずつ、計16枚が裏向きに並びます
- あなたのターンにカードを2枚クリックしてください
- 同じ絵文字なら **ペア成立**（そのままターン継続）、違えばカードが裏返ってターン交代
- コンピューターは過去にめくったカードを記憶して賢くプレイします
- 8ペアすべて揃えた時点で終了。獲得ペア数が多い方の勝ちです

## セットアップ

```bash
cd app
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。

## 技術スタック

| 項目 | 内容 |
|---|---|
| フレームワーク | React 19 + TypeScript |
| ビルドツール | Vite |
| テスト | Vitest + React Testing Library |
| 状態管理 | useReducer（外部ライブラリ不使用） |

## テスト実行

```bash
npm run test        # 対話モード
npx vitest run      # 一回実行
```
